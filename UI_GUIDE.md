## Key UI Components

### 1. **Masthead** (Top)
- Newspaper nameplate: **NewsGPT**
- Motto: "All the financial news my agents see fit to print"
- Volume, Issue, AI-generated edition note
- Dateline and story summary
- Compiled by Hermes · scrape run count

### 2. **Lead Story** (Page-wide)
- Largest, most prominent story (importance ≥ 4)
- Full headline, subheading (dek), body text
- Ticker(s) and sector label
- All source footnotes at bottom

### 3. **Column Headers** (Repeating)
- **Kicker** line: Ticker/Sector/Macro label
- **Sentiment indicator**: ▲ Positive | ▼ Negative | ◆ Mixed
- **Story count**: "3 stories"
- **Ticker list** (for sector columns): "AMD, TSM"
- **Lede paragraph**: One-sentence summary

### 4. **Full Stories** (Importance 3-5)
- Headline
- Subheading (dek)
- Body text (1-3 paragraphs, Markdown-lite: **bold**, *italic*)
- Tickers and merged count
- Footnotes with source links

### 5. **In Brief Section** (Importance 1-2)
- Compact one-liner format
- Tickers and sentiment
- Footnotes
- Appears in "In Brief" subsection of each column

### 6. **Story Footnotes** (Important!)
- Numbered superscripts: ¹²³ etc.
- Links to original sources
- Hoverable: shows title, publisher, date
- Always clickable (auditable sources)

### 7. **Footer/Colophon**
- Disclaimer about AI-generated content
- Edition date and build timestamp
- Scrape run count and source info

## Dark Mode

Toggle available in most browsers via DevTools or a CSS toggle (if implemented). The newspaper includes a full dark mode stylesheet.

**Light mode (default):**
- Cream background (#f4f1ea)
- Black text (#1a1a1a)
- Accent color: oxblood red (#7a1f1f)

**Dark mode:**
- Black background
- Light text
- Accent color: slightly muted

## Responsive Design

### Desktop (≥1024px)
- 4-5 columns full width
- Multi-column layout (text flows naturally between columns)
- Lead story spans full width
- Masthead fully expanded

### Tablet (768px – 1023px)
- 2-3 columns
- Lead story spans full width
- Masthead slightly condensed

### Mobile (<768px)
- Single column
- Lead story full width
- Masthead stacked
- Touch-friendly spacing

## Interaction

### Clickable Elements
- ✅ Story source footnotes (numbered links)
- ✅ Dark mode toggle (if present)
- ✅ Edition date links (navigation, if in legacy mode)

### Non-clickable
- Story text
- Masthead
- Column headers
- (The UI is intentionally minimal to feel like print)

## Print Stylesheet

The page includes print styles for offline archives:
- Optimized for B&W printing
- Removes colors (good for ink)
- Hides interactive elements
- Maintains column layout
- Includes all text and footnotes

**To print:** Press Ctrl+P (or Cmd+P), select "Save as PDF", choose "Backside" or "Single-sided".

## Information Density

A typical day's newspaper on desktop:
- **Lead story area**: ~40% of viewport (large)
- **Column grid**: ~60% of viewport (balanced depth)
- **Total viewable**: ~8-12 major stories + briefs above fold
- **Scrolling required**: Yes, for full depth (intentional)

The goal: read like a real newspaper, not skim a feed.

## Tips for Reading

1. **Start at the masthead** — Understand the day's coverage at a glance
2. **Read the lead story** — Most market-moving news
3. **Scan column headers** — Sentiment and story count tell you the day's flavor
4. **Follow the footnotes** — Always verify with original sources
5. **Check the colophon** — Understand which runs contributed
6. **Use dark mode** — Late-night reading

---

This UI intentionally resembles a traditional broadsheet newspaper. It's designed to be *read*, not *skimmed* — the goal is comprehension and context, not speed.
