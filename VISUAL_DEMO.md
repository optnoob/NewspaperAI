## 📱 Responsive Design

**Desktop (1200px+)**
- 5 columns side-by-side
- Full typography hierarchy
- Hover effects on links

**Tablet (768-1200px)**
- Auto-fit columns (2-3 usually)
- Adjusted font sizes
- Touch-friendly buttons

**Mobile (<768px)**
- Single column stack
- Reduced masthead (2.5rem → 1.5rem)
- Compact story cards

## 🎨 Visual Features

### Dark Mode
```
Light:              Dark:
Background: #f9f7f4 Background: #1a1a1a
Text: #1a1a1a       Text: #e0e0e0
Links: #005aa0      Links: #66b3ff
```

Toggle persists via localStorage. Smooth 0.3s transition.

### Typography Hierarchy
```
Masthead:     4rem (Georgia, 900 weight)
Lead Story:   2.5rem headline
              1.25rem dek (subheadline)
              1.1rem body

Column Story: 1.5rem headline
              1rem dek
              1rem body

Minor Story:  1.1rem headline only
              0.85rem sources
```

### Story Importance Layout
```
Importance 5 (rare):
┌─────────────────────────────────────┐
│  █ FULL-WIDTH LEAD STORY █         │

Importance 4:
┌──────────────────┐

│ Subheadline      │
│ Full body text...│
└──────────────────┘

Importance 3:
┌──────────────────┐
│ Normal Story     │

└──────────────────┘

Importance 1-2:
┌──────────────────┐

```

## 📁 File Output

Each edition is completely self-contained:

```
editions/2026-10-22/
├── index.html       (7.8 KB — includes embedded JSON)
├── app.js           (5.9 KB — rendering logic)
└── style.css        (5.4 KB — newspaper styles)
────────────────────
Total: ~19 KB        Works offline, no dependencies
```

**Zero external dependencies:**
- ❌ No CDN fonts
- ❌ No icon libraries
- ❌ No JavaScript frameworks
- ❌ No web server needed
- ✅ Just HTML/CSS/vanilla JS
- ✅ Works via `file://` protocol

## 📊 Column Grouping Logic

Stories are automatically grouped:

```
Input Stories:
- "NVDA Rallies..." (tickers: ["NVDA"])
- "TSM Raises..." (tickers: ["TSM"])
- "AMD Announces..." (tickers: ["AMD"])
- "Oil Drops..." (sector: "Energy")
- "Fed Minutes..." (sector: "Macro")

Output Columns:
┌─────┬─────┬─────┬────────┬───────┐
│NVDA │ TSM │ AMD │ Energy │ Macro │
└─────┴─────┴─────┴────────┴───────┘
```

Each ticker gets its own column (if lead ticker).
Fallback to sector if no ticker specified.
